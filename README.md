# Student Score Prediction

## 🤖 AI & Machine Learning Internship

Welcome to my **AI & Machine Learning Internship** repository. This repository documents my daily learning, practical tasks, and project development throughout the internship.

The main project is a **Student Score Prediction system** built using **Machine Learning and Linear Regression**. The project covers the complete workflow from Python programming and data analysis to data visualization, model training, evaluation, prediction, and deployment through a Flask web application.

---

## 📌 Project Objective

The objectives of this internship project are to:

* Build a strong foundation in Python programming.
* Understand the fundamentals of Artificial Intelligence and Machine Learning.
* Perform data analysis using NumPy and Pandas.
* Clean and prepare datasets for Machine Learning.
* Visualize relationships between student performance features.
* Build and train a Linear Regression model.
* Evaluate the model using MAE, MSE, and R² Score.
* Predict student final scores.
* Develop a Flask-based web application for score prediction.
* Organize the complete project into a professional structure.

## 📊 Machine Learning Project

The Student Score Prediction model predicts a student's **Final Score** using the following features:

### Features

* Hours Studied
* Attendance
* Previous Score

### Target

* Final Score

### Model

**Linear Regression**

The model learns the relationship between the selected student performance features and the final examination score.

---

## 📈 Model Evaluation

The trained model is evaluated using:

* **Mean Absolute Error (MAE)**
* **Mean Squared Error (MSE)**
* **R² Score**

These metrics are used to measure the prediction accuracy and performance of the Linear Regression model.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/AnandVishwakarma24/student-score-prediction.git
```

### 2. Navigate to the Project

```bash
cd student-score-prediction
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Prediction Application

Navigate to the Day-11 folder:

```bash
cd Day-11
```

Run the Flask application:

```bash
python Day-11_Prediction_App.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000/
```
