# Student Score Prediction System

AI & Machine Learning Internship Project — **Codomax Digital Solutions**

## About

A Machine Learning project that predicts student examination scores based on study hours, built as part of a 14-day AI & ML Internship at Codomax Digital Solutions. The project covers the full ML workflow — data preprocessing, visualization, model training, prediction, and evaluation.

## Objective

To build a Linear Regression model that predicts a student's exam score using the number of hours studied.

## Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

Study hours vs. examination scores.

## Model

Linear Regression (Scikit-learn), evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
